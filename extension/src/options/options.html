屏蔽弹窗广告、视频贴片/暂停广告、搜索引擎广告（Chrome / Edge MV3）

总览

启用 AdCleaner 关闭后停用全部规则集，页面元素也不会被隐藏。
视频激进模式 默认关闭。开启后对未知视频站点也会「静音 + 16 倍速」尝试跳过广告；可能误伤正常播放，请谨慎开启。
弹窗激进模式 默认关闭。开启后会拦截「合成点击触发的 window.open」；个别站点的正常弹窗（客服、分享）可能受影响。

规则集

    网站白名单

    每行一个域名（可含子域，如 www.example.com）。白名单内的网站不做任何隐藏与拦截。

    规则来源与许可

    规则集由 npm run build:rules 转换生成，来源见 extension/rulesets/_sources.json。转换工具为 @adguard/dnr-converter（GPL-3.0，仅构建期使用）。

    设置导出 / 导入

    导出为 JSON 文本（含规则集开关、白名单、激进模式；不含统计）。导入会覆盖现有设置。

    已知限制

    • YouTube 已服务端合流广告（SSAI/SABR），客户端只能在数据层与播放器层尽力加速/跳过，无法保证 100% 去广告。
    • 国内视频站可能检测广告拦截并降级清晰度或要求关闭拦截，属正常现象。
    • 本作品仅供个人使用；公开分发/上架前请自行确认各过滤列表的许可条款（见 README 许可表）。
